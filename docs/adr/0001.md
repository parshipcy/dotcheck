# ADR 0001: How dotcheck audits env files

## Status
Accepted

## Context
Cloned apps often miss or blank env vars. We needed a small Node CLI for CI that never leaks secrets.

## Decision
- Source of truth: `.env.example`. Actual: `.env` (missing = empty map).
- Findings: missing / empty / unused. Optional = comment `# optional` above a key.
- Report keys and kinds only; never values.
- Exit 0 = ok or warnings, 1 = required issues (or `--strict`), 2 = tool/usage error.
- ESM TypeScript CLI; parse args by hand (no extra deps).

## Consequences
Easy to test (pure parse + audit). No code-scanning. Users must keep `.env.example` accurate.
